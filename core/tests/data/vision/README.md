# Camera frames for vision tests

Real frames, kept to check the vision functions on what cameras actually see.

| File | What it shows |
|---|---|
| `vls6045ex-bottom.webp` | A TDK VLS6045EX wound inductor (6 × 6 mm) on a nozzle, from a LumenPnP's bottom camera, 1920 × 1080, 0.01305 mm per pixel (the machine's calibration). Its two terminals are 1.7 × 4.8 mm, 2.6 mm apart; the copper wire ends shine below them. |
