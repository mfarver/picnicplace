# PicnicPlace hardware

Boards PicnicPlace publishes for owners to order. Each is a KiCad 10 board generated by
a script next to it, which holds every dimension: change the numbers there and run it
again, rather than editing the board by hand (touch-ups made in KiCad are lost on the
next run).

| Folder | Board | Described in |
|---|---|---|
| `datum/` | The datum: an L-shaped PCB whose corner, set by four pins, locates boards, with the targets that calibrate the machine; and its 3D-printed holder (CadQuery) | [docs/hardware/picnicplace-datum.md](../docs/hardware/picnicplace-datum.md) |
| `panel-enclosure/` | The control panel's enclosure: a 3D-printed case for the Waveshare 7B and a 22 mm E-stop, with a bracket to the machine's rail (CadQuery, not KiCad) | [docs/hardware/control-panel.md](../docs/hardware/control-panel.md#the-enclosure) |
| `test-board/` | The test board: targets for measuring how accurately the machine places, with nothing soldered | [docs/hardware/test-board.md](../docs/hardware/test-board.md) |
| `token/` | The calibration token that stop 2 picks up and turns, and a 100 × 100 mm panel of 144 to order | [docs/hardware/calibration-token.md](../docs/hardware/calibration-token.md) |

## Regenerate a board

The scripts need KiCad's own Python, which has the `pcbnew` module and KiCad's footprint
libraries. On macOS:

```sh
KICAD_PYTHON=/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3
$KICAD_PYTHON hardware/datum/make_datum.py
$KICAD_PYTHON hardware/test-board/make_test_board.py
$KICAD_PYTHON hardware/token/make_token.py   # also needs KiKit, for the panel
```

The datum's logo is traced from `logo/picnicplace-icon-bw.png` into
`logo/picnicplace-icon-outline.json`, which the datum script draws. KiCad's Python has no
image library, so the tracing runs with the core's environment; after changing the
picture, run `cd core && uv run python -I ../hardware/logo/make_logo_outline.py`, then the
datum script.

The datum's holder is a CadQuery script instead (CadQuery 2.4 or later, in any Python
environment): `python hardware/datum/make_holder.py` writes STEP and STL files to
`hardware/datum/out/`.

Then check it with KiCad's design rules (`kicad-cli` is in the same app bundle, under
`Contents/MacOS`):

```sh
kicad-cli pcb drc --severity-all hardware/test-board/picnicplace-test-board.kicad_pcb
```

KiCad's Python is 3.9, so the scripts avoid newer syntax. They are not part of
`make check`.

The panel's enclosure is a CadQuery script instead (CadQuery 2.4 or later, in any Python
environment): `python hardware/panel-enclosure/make_enclosure.py`.

Design coordinates are in millimeters, from the corner a board is pushed into: +X right,
+Y toward the back of the machine. KiCad's grid and drill origins are set to that corner,
so placement files exported with the drill origin read in the same coordinates.
