# PicnicPlace hardware

Boards PicnicPlace publishes for owners to order. Each is a KiCad 10 board generated by
a script next to it, which holds every dimension: change the numbers there and run it
again, rather than editing the board by hand (touch-ups made in KiCad are lost on the
next run).

| Folder | Board | Described in |
|---|---|---|
| `datum/` | The datum: an L-shaped PCB whose corner, set by three pins, locates boards, with the targets that calibrate the machine | [docs/hardware/picnicplace-datum.md](../docs/hardware/picnicplace-datum.md) |
| `test-board/` | The test board: targets for measuring how accurately the machine places, with nothing soldered | [docs/hardware/test-board.md](../docs/hardware/test-board.md) |

## Regenerate a board

The scripts need KiCad's own Python, which has the `pcbnew` module and KiCad's footprint
libraries. On macOS:

```sh
KICAD_PYTHON=/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3
$KICAD_PYTHON hardware/datum/make_datum.py
$KICAD_PYTHON hardware/test-board/make_test_board.py
```

Then check it with KiCad's design rules (`kicad-cli` is in the same app bundle, under
`Contents/MacOS`):

```sh
kicad-cli pcb drc --severity-all hardware/test-board/picnicplace-test-board.kicad_pcb
```

KiCad's Python is 3.9, so the scripts avoid newer syntax. They are not part of
`make check`.

Design coordinates are in millimeters, from the corner a board is pushed into: +X right,
+Y toward the back of the machine. KiCad's grid and drill origins are set to that corner,
so placement files exported with the drill origin read in the same coordinates.
