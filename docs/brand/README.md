# PicnicPlace brand assets

| File | Use |
|---|---|
| `picnicplace-logo.png` | Original artwork, 1264 × 1264. Source for the website and any new sizes. |
| `picnicplace-logo-cropped.jpg` | Cropped to the illustration and wordmark, 624 × 560. Used in the README. The Studio splash uses a copy in `studio/src/assets/splash.jpg`. |

The artwork's background color is `#c0d4d2`. Use it behind the logo so the edges blend.

The PicnicPlace name and logo identify the official project. Forks may use the code under
the MPL-2.0 but should not present themselves with the PicnicPlace name or logo (see the
trademark notes in [the specification](../SPEC.md#14-licensing-decided)).
